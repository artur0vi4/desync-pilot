# Desync Pilot

Автопилот обхода DPI: сам подбирает стратегию десинхронизации, мониторит
соединение, переключается сам и живёт в трее. Никаких `.bat` с ручным перебором.
DNS — только в виде рекомендации: программа ничего не меняет сама.

Внутри — движок `winws.exe` из [zapret-discord-youtube 1.10.4](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.4)
и каталог из **191 стратегии**: 22 базовые из апстрима плюс 169 пресетов сообщества
из [zapret-gui](https://github.com/zapretdiscordyoutube/zapretgui) (Zapret 2 GUI).
После фильтра группы `experimental` в работе остаётся 190.

## Что внутри

- **Полный набор бинарей zapret 1.10.4**: `winws.exe`, `WinDivert.dll`,
  `WinDivert64.sys`, `cygwin1.dll`, все `.bin` (TLS ClientHello / QUIC initial / Discord / STUN).
- **Каталог из 191 стратегии** (`strategies.json` + `strategies_gui.json`): группы
  `base`, `alt`, `fake_tls_auto`, `simple_fake`, `community`, `game`, `experimental`.
  В таблице есть поиск по названию/группе/режиму, фильтр по группе и колонка «Источник».
- **Быстрый подбор с разнообразным порядком**: каталог — это в основном варианты
  одних и тех же техник (191 стратегия сходится к ~85 «методовым семействам»),
  поэтому автопилот идёт не по каталогу подряд, а перескакивает между семействами:
  все 85 покрываются первыми 85 попытками вместо 170 при наивном порядке.
  Стратегии, которые уже работали на этой сети (кэш `state.json`), всегда идут первыми.
- **«Принять или продолжить?»**: как только при подборе нашлась полностью рабочая
  стратегия, программа предлагает её принять; можно продолжить поиск более удачной.
  Если ответа нет 45 с (окно свернуто в трей), стратегия принимается автоматически —
  автопилот не зависает без присмотра. Отключается галкой «Предлагать принять первую
  найденную стратегию» (тогда первый результат принимается сразу).
- **Полный прогон** — кнопка «Перетестировать»: все стратегии, все цели (тоже с тем же
  вопросом на первом полном попадании), отменяется кнопкой «Остановить».
- **DNS-рекомендация**: публичные resolver'ы (Cloudflare, Google, Quad9, Yandex, AdGuard,
  OpenDNS, NextDNS, ControlD, Mullvad и др.) один раз в фоне измеряются по RTT, самый
  быстрый показывается на вкладке «Статус» (кэш на 6 часов). Ничего не переключается —
  хотите, впишите адрес в настройки сетевого адаптера сами.
- **Локальный DoH-прокси** (опционально, порт 5354) — заменяет `dnsproxy.exe`. Запросы идут через DoH
  к выбранному провайдеру или к своему URL. Включается в настройках (DNS-стратегия `hybrid`/`doh_only`).
- **Health-монитор** каждые 30 мин (настраивается) перепроверяет доступность ключевых
  сервисов; при деградации запускает повторный тест и переключается на лучшую стратегию.
  Если `winws.exe` умер — перезапускает его за секунды.
- **PyQt6 UI** с тёмной темой, RU/EN локализацией, иконкой в трее, toast-уведомлениями (Windows 10/11),
  экспортом лога, диалогом настроек.
- **Кэш результатов** (`state.json` в `%APPDATA%\desyncpilot`): повторный запуск не
  перебирает каталог заново, а сразу поднимает лучшую из кэша (TTL настраивается).
- **Диагностика** — отдельная вкладка, которая отвечает на вопрос «где именно режут»:
  подмена DNS, блокировка по IP, обрыв по имени (SNI), TLS-фильтр, заглушка провайдера,
  чужой сертификат. Плюс локальные проверки: права администратора, файлы движка,
  драйвер WinDivert, конфликтующие программы и VPN, системный прокси, записи в hosts,
  занятость порта 5354. В конце — вердикт и рекомендованная стратегия.
- **Автозапуск при входе в Windows** (`HKCU\...\Run`, флаг `--minimized`).
- **Один экземпляр**: второй запуск не плодит конкурирующие `winws.exe` и не отбирает порт 5354.
- **GitHub Actions** workflow: тесты, сборка Windows-бандла через PyInstaller, SHA-256 и
  автопубликация релиза при пуше тега `v*`.

## Установка (готовый билд)

1. Скачай `DesyncPilot-vX.Y.Z.zip` из [Releases](../../releases) и распакуй.
2. Запусти `DesyncPilot.exe`. Подтверди запрос прав администратора (нужен для WinDivert).
3. Программа:
   - если в кэше нет свежего результата — выполнит быстрый подбор с разнообразным
     порядком (обычно 10–40 секунд); на первой полностью рабочей стратегии спросит
     «Принять или продолжить поиск» (45 с без ответа = принять);
   - проверит победителя по всем целям и оставит его активным;
   - в фоне измерит публичные DNS и покажет рекомендацию на вкладке «Статус»;
   - свернётся в трей, продолжая мониторить соединение каждые 30 мин.
   Повторный запуск берёт лучшую стратегию из кэша и стартует за секунды.
4. (Опционально) Включи в настройках DNS-стратегию `hybrid` и укажи DNS `127.0.0.1`
   в настройках сетевого адаптера, чтобы пользоваться локальным DoH-прокси как
   системным резолвером. Без этого обход DPI работает и так (WinDivert не зависит от DNS).

## Каталог стратегий

`strategies_gui.json` собирается из пресетов zapret-gui (`src/presets/builtin/winws1/*.txt`).
Их формат — один аргумент `winws.exe` на строку, `#`-метаданные, `--new` между секциями.
Конвертер (`app/preset_parser.py`) делает из него наш JSON:

- выкидывает `--comment` (информационный шум);
- раскрывает многострочные значения (`--wssize` + `1:6`, списки `--ipset-exclude-ip`);
- чинит одиночный дефис в одном из файлов;
- подставляет отсутствующие у нас `.bin` и списки домен/IP из комплекта
  (структура десинка сохраняется, меняется только содержимое фейк-пакета);
- убирает дублирующиеся после подстановки секции и дубликаты стратегий.

Пересобрать каталог:

```bash
python scripts/import_presets.py --dir path/to/winws1     # из локальной папки
python scripts/import_presets.py --cache-dir .presets-cache  # скачать из репозитория zapret-gui
```

Флаги из пресетов сверяются со списком, вытащенным из самого `bin/winws.exe`: если
пресет использует незнакомый флаг, он отбрасывается, а не ломает прогон.

## Как считается оценка стратегии

Для каждой стратегии тестируются цели из `utils/targets.txt` (по умолчанию 12: Discord web/gateway/CDN/updates,
YouTube web/short/image/redirector, Google/gstatic, Cloudflare/CDN), у каждой цели свой вес. Сначала проверяются
первые четыре «канарейки» (Discord, YouTube, Google, Cloudflare): если не открылась ни одна, стратегия
считается мёртвой и остальные цели не проверяются.

```
reach     = сумма весов доступных целей / сумма всех весов
base      = 100 * reach
latency   = +40 максимум, линейно: 100 мс -> +40, 1 с -> 0
full      = +20 если достигнуты все цели
score     = base + latency + full
```

## Настройки

- **Автоматический режим** — программа сама подбирает стратегию.
- **Быстрый подбор** — проверять первые N пресетов по канарейкам вместо полного прогона.
- **Предлагать принять первую найденную стратегию** — диалог «Принять / Продолжить поиск»
  на первом рабочем результате (галка) и таймаут автопринятия (5–300 с).
- **Перепроверять каждые N минут** — интервал health-монитора (5–240).
- **Использовать кэш теста (мин)** — сколько минут можно доверять сохранённому результату
  прогона (0 = тестировать при каждом запуске).
- **DNS-стратегия**: `hybrid` (локальный DoH + системный fallback), `doh_only`, `system` (выкл).
- **DoH provider** — авто, конкретный из списка или свой URL.
- **Probe timeout / attempts** — параметры тестирования.
- **Запускать при входе в Windows** — регистрирует программу в автозагрузке (без прав администратора).
- **Export log dir** — куда складывать экспортируемые логи.

## Обновление стратегий с GitHub

Кнопка **«Обновить стратегии»** на вкладке «Стратегии» (и автоматическая проверка при старте,
если `auto_update_strategies = true`) забирает свежий релиз апстрима через GitHub API, вытаскивает
из архива `.bat`, перегенерирует `strategies_remote.json` в `%APPDATA%\desyncpilot` и
применяет его при следующем запуске. Скачивание идёт потоком, размер архива ограничен,
пути внутри архива проверяются. Каталог сообщества обновляется скриптом `scripts/import_presets.py`.

  controller.py        — связывает core и UI, отмена прогонов, кэш, быстрый подбор
  config.py            — config.ini (секция [desyncpilot], читает и старую [zapret])
  paths.py             — пути в frozen/normal режимах, миграция старого каталога данных
  logger.py            — ротация + ring buffer для live-лога
  i18n.py              — RU/EN
  strategies.py        — загрузка каталога, запуск winws.exe, preflight
  winws_args.py        — общие правила разбора аргументов winws (пути, списки портов)
  strategy_parser.py   — парсер upstream .bat -> strategies.json
  preset_parser.py     — конвертер пресетов zapret-gui -> strategies_gui.json
  tester.py            — полный тест, быстрый скан по канарейкам, scoring
  diagnostics.py       — где режут: DNS / IP / SNI / TLS / заглушка + локальные проверки
  autostart.py         — регистрация в HKCU\...\Run
  health.py            — health-монитор + watchdog winws.exe
  updater.py           — проверка/загрузка релизов с GitHub
  toasts.py            — Windows toast-уведомления
  dns/
    servers.py         — список DoH-серверов
    resolver.py        — DoH-резолвер + speed-test
    proxy.py           — локальный UDP DoH-прокси (пул потоков + кэш)
    manager.py         — опциональный DoH-прокси (включается в настройках)
    advisor.py         — фоновая рекомендация DNS (кэш dns_recommend.json)
  ui/
    main_window.py     — главное окно (5 табов), диалог «Принять / Продолжить поиск»
    tray.py            — иконка в трее
    settings_dialog.py — настройки
    widgets.py         — Card, KV, Badge, FlowLayout
    resources.py       — QSS + SVG-иконки
bin/                   — winws.exe, WinDivert*.dll/sys, cygwin1.dll, *.bin
lists/                 — list-general.txt, list-google.txt, list-exclude.txt, ipset-*.txt
utils/targets.txt      — цели для теста
strategies.json        — базовые стратегии из апстрима
strategies_gui.json    — каталог сообщества (zapret-gui, winws1)
scripts/parse_strategies.py — CLI-обёртка парсера .bat
scripts/import_presets.py   — сборка каталога сообщества

DesyncPilot.spec       — PyInstaller spec
.github/workflows/build.yml — CI/CD

## Тесты

```bash
python -m unittest discover -s tests -t . -v
```

Тесты не ходят в сеть и не требуют прав администратора: разбор аргументов winws,
preflight, скоринг, ранний выход и отмена прогона, быстрый скан, колбэк «принять/продолжить»,
разнообразный порядок перебора и сигнатуры стратегий, парсер `.bat`,
конвертер пресетов (многострочные значения, подстановка ассетов, дедупликация),
конфиг, ring-буфер лога, DNS-запросы и кэш прокси, классификатор диагностики,
автозапуск. CI гоняет их перед сборкой бандла.

## Известные ограничения

- WinDivert требует прав администратора. При первом запуске будет UAC-запрос.
- Toast-уведомления только на Windows 10/11. На старых ОС логируются в файл.
- Локальный DoH-прокси слушает только `127.0.0.1`; чтобы сделать его системным DNS,
  нужно вручную прописать `127.0.0.1` в настройках адаптера.
- Гибридный DNS-режим не подменяет системный резолвер автоматически: автоматическое
  изменение системного DNS чревато потерей сети при сбое программы.
- Каталог сообщества — это winws1-часть zapret-gui. Их winws2-пресеты (Zapret 2, Lua)
  требуют другого движка и в поставку не входят.
- В пресетах сообщества отсутствующие у нас списки домен/IP заменены нашими общими
  (`list-general.txt`, `ipset-all.txt`): структура десинка сохранена, по-сервисная
  таргетировка — нет.

## Что взято из соседнего проекта

Идеи и каталог — у [zapret-gui](https://github.com/zapretdiscordyoutube/zapretgui) (Zapret 2 GUI),
код написан свой:

- **Каталог пресетов** (169 winws1-пресетов) — сконвертирован в наш формат, ассеты подставлены.
- **Диагностика «где режут»** — их blockcheck различает блокировку по IP, по SNI, TLS по ответу
  сервера, заглушку и т.п. У нас — облегчённая версия без браузера и разбора netlog: те же приёмы
  (сравнение «реальное имя vs чужое имя на том же адресе», сверка системного DNS с DoH), но
  в одном модуле `app/diagnostics.py`.
- **Автозапуск при входе в Windows** (у них — отдельный модуль, у нас — `app/autostart.py`).
- **Свой DoH-сервер** помимо встроенного списка.

Сознательно не берём: hosts-разблокировку ChatGPT/Notion (правим системный файл — слишком
инвазивно для автопилота) и поддержку Zapret 2 (`winws2.exe` + Lua в поставке нет).
