# Security Policy / Политика безопасности

Desync Pilot — приложение для Windows, которое **запускается с правами
администратора** и управляет драйвером WinDivert (`winws.exe`). Ошибка в таком
приложении — это не «краш», а потенциальная эскалация привилегий, поэтому
сообщайте о проблемах аккуратно.

## Что считается уязвимостью

- **DLL hijacking / подмена библиотек**: поиск DLL рядом с exe (`bin/`, каталог
  установки), позволяющий выполнить свой код с правами администратора.
- **Эскалация привилегий**: обход UAC, некорректная обработка аргументов
  при перезапуске через `ShellExecuteW(... "runas" ...)`.
- **Инъекция через пользовательские данные**: `config.ini`, `utils/targets.txt`,
  сторонние `.bat`-пресеты, пути в списках — приводящие к выполнению команд или
  записи за пределы каталога приложения.
- **Локальный DNS-прокси**: порт 5354 на `127.0.0.1` — подмена ответов,
  открытие порта на внешних интерфейсах, DoH-редиректы.
- Небезопасная загрузка обновлений каталога стратегий (подмена источника,
  отсутствие проверки содержимого).

## Как сообщать

**Только через GitHub Security Advisories** (приватно):

1. Откройте https://github.com/artur0vi4/desync-pilot/security/advisories/new
2. Опишите: версию (коммит/тег), шаги воспроизведения, ожидаемый vs фактический
   результат, PoC при наличии.
3. Не публикуйте детали в публичных Issues, обсуждениях и социальных сетях до
   согласованной даты раскрытия.

Мы стараемся отвечать в течение нескольких дней, работаем по принципу
координированного раскрытия и укажем ваше авторство в фиксах, если вы того
захотите.

## Что НЕ считается уязвимостью

- Эффективность/обнаружимость самого обхода DPI — это предметная часть проекта.
- Краш приложения без последствий для безопасности.
- Проблемы сторонних бинарников (`winws.exe`, `WinDivert.dll/sys`, `cygwin1.dll`
  из [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)):
  их репортите апстриму, но если в нашем коде они используются небезопасно —
  сообщайте нам.

## Поддерживаемые версии

Обновления безопасности выпускаются для **последнего релиза** (см. теги `v*`
на странице Releases). Более старые версии не поддерживаются.

## Замечание для контрибьюторов

Любой код, который формирует командную строку `winws.exe` или пути к файлам из
пользовательских данных, должен экранировать аргументы (`app/main.py::
_escape_arg`, `app/winws_args.py`) и проверять границы значений
(`app/config.py::_INT_BOUNDS`). При сомнениях — спрашивайте в PR.
